# C盘清理工具（C Drive Cleaner）

> 一个用 AI 协助开发的 Windows C 盘清理工具。纯 Python 单文件，无依赖，绿色运行。

**当前版本：v3.0** | 适用于 Windows 7 SP1+ / 10 / 11（32 位与低配机亦可）

## 功能

| 模块 | 说明 |
|------|------|
| 垃圾清理（36 类） | 系统临时 / AI 模型 / Python·npm·uv 缓存 / 崩溃转储 / 应用专属（钉钉·Obsidian·WorkBuddy 等） |
| 浏览器缓存（细分 8 类） | 网页 / 渲染 / 组件与崩溃 / 根级数据 / 站点数据 / ServiceWorker 配额 / Firefox 缓存 / Firefox 深度——各自标注风险，可按需单独勾选，避免误清登录态 |
| 隐私痕迹 | 最近文档 / Jump Lists / 剪贴板历史 / 事件日志 |
| Deep Scan | 全盘精确正则搜索垃圾文件（.bak / 编辑器备份 / __pycache__ 等） |
| 系统瘦身 | DISM WinSxS 组件清理 |
| 大文件猎手 | 定位 >100MB 文件 |
| 无效快捷方式 | 桌面/开始菜单死链检测（IShellLink COM 精确解析） |
| **驱动管理** | pnputil 旧版本驱动识别与删除——A区：同款多版本旧版（`[1]` 仅无风险 / `[2]` 仅低风险）；B区：孤立驱动包分安全等级（`[3]` 安全孤立包·外设残留放心删 / `[4]` 注意孤立包·核心硬件可能未来回插），删除后 Windows Update 可重新获取 |
| **AppX 管理** | 预装 UWP 列出与卸载（37 关键词黑名单保护系统/硬件/媒体组件） |

## 安全设计

- **风险三级分级**：安全（自动重建）/ 注意（需确认）/ 谨慎（不可逆）
- **驱动/AppX 操作前自动创建系统还原点**
- **删除操作全量日志**：每次清理生成 `clean_log_时间戳.txt`，逐条可追溯
- **累计清理统计**：每次清理结束显示"本次清理 X · 累计清理 Y · 共 N 次"（持久化于 `%LOCALAPPDATA%/CDriveCleaner/cleanup_stats.json`）
- **宁缺毋滥**：所有清理路径经本机实测验证，不猜测
- 驱动删除**不带 /force**（在用驱动系统自动拒绝）

## 快速开始

```bash
# 方式一：直接双击 C盘清理.bat（自动寻找 Python 环境）
# 方式二：命令行
python c_drive_cleaner.py
```

**没有安装 Python？也能用**：启动器会自动检测并下载便携运行时（~11MB，华为云→npmmirror→python.org 三镜像容错，大陆直连快速），解压到 `runtime\` 后即开即用，整目录拷走即可。

**旧系统/低配机适配**：Windows 7 SP1+（自动选 Python 3.9.13）、32 位系统（自动选 win32 包）、CPU<5 核自动降并发——无 Python 环境、低内存也能跑。

## 首次使用建议

1. 以管理员身份运行（脚本会自动弹 UAC）
2. 先选 `[1] 垃圾清理` 扫描，查看可清内容——浏览器缓存已细分为 8 类，可按需勾选
3. 驱动管理 `[7]`：A区选 `[1]` 仅删无风险档、`[2]` 仅删低风险档；B区 `[3]` 删孤立驱动包（无设备引用）；或 `[a]` 全部（删前自动建还原点）
4. 清理后重启一次，确认设备管理器无异常

## 常见问题

**Q: 驱动管理显示"没有可安全删除的旧版本"？**
A: 正常——所有候选驱动都在使用中。这恰恰说明你的驱动商店很干净。

**Q: 删除的 AppX 还能找回吗？**
A: 可以。Microsoft Store 中重新安装即可。

**Q: 清理会误删我的数据吗？**
A: 不会。脚本只清理缓存/临时/日志类文件，所有路径经实测验证；删除前可查看完整清单。
